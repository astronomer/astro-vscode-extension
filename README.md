# Astro for VS Code

Issues and feedback for **Astro for VS Code**, Astronomer's extension that brings Airflow and Astro into your editor:
chat with [Otto](https://www.astronomer.io/docs/astro/otto/otto-overview), Astronomer's Airflow agent, triage your
Deployments and your local Airflow, and search the Airflow docs without leaving the editor.

This repository holds no source code. It is where to report a problem or ask for a feature.

## Install

Install **Astro for VS Code** by Astronomer from the
[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Astronomer.astronomer-vscode), or from the
Extensions view in VS Code.

You need an Astronomer account and the [Astro CLI](https://www.astronomer.io/docs/astro/cli/overview/). Sign in
with **Astro: Sign In** from the command palette, or run `astro login` in a terminal.

## Report a problem

[Open an issue](https://github.com/astronomer/astro-vscode-extension/issues/new/choose) and include:

- The extension version (Extensions view → Astro),
- Your editor and its version,
- Your operating system,
- The output of `astro version`,
- What you did, what you expected, and what happened instead,
- The relevant part of the **Astro** output channel (View → Output → Astro).

Before pasting a log, check it for anything you would rather not share publicly, such as file paths or project names.
The extension never writes credentials to it.

For problems with your Astronomer account, a Deployment, or anything else that is not the extension itself, contact
[Astronomer support](https://www.astronomer.io/docs/astro/astro-support).

## Report a security vulnerability

Do not open an issue. Email [oss_security@astronomer.io](mailto:oss_security@astronomer.io) instead.
